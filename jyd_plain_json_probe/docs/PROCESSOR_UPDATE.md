# 剪映批量剪辑工作台更新说明

这个压缩包只用于更新已经安装好的工作台。它会携带并合并官方语义贴图素材库，以及覆盖
官方音乐语义标签 `data/libraries/audio_library/manifest/music_profiles.v1.json`；不会携带
音乐文件、音频素材清单、ASR 运行时、用户任务、密码、配置、个人素材库或其他历史数据。

## 更新步骤

1. 等待正在导出的任务结束。
2. 关闭 `JianyingRenderServer.exe` 的黑色运行窗口。
3. 备份原工作台目录中的 `data` 文件夹。
4. 解压本更新包，把全部文件复制到原工作台目录并选择覆盖；其中官方语义贴图目录会合并更新，
   官方音乐语义标签会更新到当前版本。
5. 不要先删除原来的 `data` 文件夹；直接覆盖合并不会删除任务、密码、配置和其他素材。
6. 双击新的 `JianyingRenderServer.exe`。
7. 打开网页，确认母版、素材和最近任务仍然存在。

如果不确定哪个是原工作台目录，请不要更新，先联系维护人员。把更新包解压到新文件夹单独运行，会得到一个没有原素材和任务记录的新工作台。

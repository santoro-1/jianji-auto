## 已完成

- 高版本草稿自动解密、分析、上传和模板库存储；处理机生成输出副本时会把原生高版本草稿的版本封套转换为剪映 5.9 兼容值，原始母版保持不变。
- 输出草稿复制后会重建剪映目录元数据（名称、目录、草稿 ID 和时间），并在导出前等待剪映首页完成识别，避免磁盘已有草稿但自动导出报 `DraftNotFound`。
- 新增视频特效默认覆盖完整草稿时间线，支持母版包含多段视频和中间转场；本机采集器会读取剪映草稿索引并比较各磁盘有效草稿活动时间，自动选择实际使用的草稿目录。
- 从 MP4 自动创建基础明文剪映草稿。
- 音乐、视频特效、全屏贴纸、花字、复合文字模板和字体素材的采集工具。

## 当前目标

普通用户上传成片 MP4，或通过本地采集器上传剪辑母版；系统按选定音乐、视频特效、全屏贴纸和字幕字体生成多个组合，使用专用 Windows 处理机上的剪映顺序导出 MP4，并在网页中预览和下载。

## 已完成

- 高版本草稿自动解密、分析、上传和模板库存储；处理机生成输出副本时会把原生高版本草稿的版本封套转换为剪映 5.9 兼容值，原始母版保持不变。
- 输出草稿复制后会重建剪映目录元数据（名称、目录、草稿 ID 和时间），并在导出前等待剪映首页完成识别，避免磁盘已有草稿但自动导出报 `DraftNotFound`。
- 新增视频特效默认覆盖完整草稿时间线，支持母版包含多段视频和中间转场；本机采集器会读取剪映草稿索引并比较各磁盘有效草稿活动时间，自动选择实际使用的草稿目录。
- 从 MP4 自动创建基础明文剪映草稿。
- 音乐、视频特效、全屏贴纸、花字、复合文字模板和字体素材的采集工具。
- 字体文件内部名称识别、字体库清单和网页真实字体预览。
- 上传 MP4 后新增长文案字幕，并设置字体、基础样式、字号、颜色和位置。
- 剪辑母版只替换普通字幕字体，保留内容、时间、字号、颜色、描边、位置和复合文字模板。
- 音乐、特效、贴纸和字体的排列组合，单批上限 500。
- 单机顺序渲染队列、任务状态、失败重试和取消未开始任务。
- 结果视频网页预览、单个或批量下载、手动删除和自动到期清理。
- 永久素材库与临时上传/输出文件的存储生命周期分离；本地采集器上传的剪辑母版默认保留 48 小时，并避开仍在排队或运行的任务。
- 网页批量任务编辑器支持多选本机母版后自动生成任务行、统一设置选中任务和逐行调整；批量上传的母版标记为批次临时母版，批次全部成功或取消后立即删除母版本体、导入记录和原始 ZIP，任务失败时暂留以支持重试，最长 24 小时兜底清理。
- 永久素材管理页：搜索、分页、重命名、分类、启用/停用、预览、回收站和恢复。
- 普通用户页与后台页面隔离，后台页面、接口文档和管理接口均有管理员登录鉴权。
- 本地采集器已打包为免安装 Windows ZIP，内置 Python、依赖和 `jy-draftc`，可自动识别剪映安装目录并保存本地诊断日志。
- 处理机后端已打包为免安装 Windows ZIP，内置网页、依赖、解密工具和现有永久素材库，默认监听局域网并自动显示访问地址。
- 处理机素材、模板、任务和输出统一放在发布包 `data` 目录，复制母版后的旧绝对路径会在首次启动时自动重定位。

## 上线前主要缺口

1. **本地采集器正式分发体验**
   当前已有可运行的免安装 Windows ZIP、处理机地址配置和错误日志。正式大规模分发仍可补安装器、数字签名、自动更新、上传进度和更完整的依赖检测。

2. **真实剪映闭环回归**
   需要分别验证“上传 MP4 新建草稿”和“剪辑母版替换字体”两条路径，确认草稿可打开并能自动导出 MP4。按当前安排留到高版本账号资源采集完成后执行。

3. **部署和普通用户访问控制**
   管理员权限已经完成。局域网阶段还需要处理机固定地址、服务监听 `0.0.0.0` 和防火墙规则；公网阶段需要域名、HTTPS、普通用户登录、采集器上传令牌、上传限制和审计日志。

## 部署扩大时再做

- 当前渲染队列只适合一台 Windows 处理机和一个剪映实例。
- 多台处理机需要中央任务服务、处理机注册/心跳、任务领取、失败转移和结果上传。
- 模板及素材描述信息适合进入数据库；大文件仍存放在磁盘或对象存储，数据库只保存元数据和路径。

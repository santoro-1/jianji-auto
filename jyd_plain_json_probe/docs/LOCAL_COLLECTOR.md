# 剪映草稿采集工具使用说明

这个工具负责读取当前电脑上的剪映草稿，并把选中的草稿或素材送到“剪映批量剪辑工作台”。它不会自动导出视频。

本机完整工作台已经内置该功能，不需要另外启动本工具。只有当前电脑不运行完整工作台、而是通过浏览器访问其他公用工作台时，才需要单独使用这个采集工具。

程序已经包含运行环境，不需要安装 Python、Anaconda，也不需要输入命令。

## 使用前准备

1. 当前电脑已经安装剪映专业版。
2. 要采集的草稿能够在剪映中正常打开。
3. 把整个 ZIP 解压后使用，不要直接在压缩包里运行，也不要只复制 EXE。

## 每次怎么用

1. 双击 `JianyingDraftCollector.exe`。
2. 工具启动后会在后台运行，保持它开启。
3. 再打开“剪映批量剪辑工作台”。
4. 在工作台选择“上传草稿”或“个人素材”。
5. 点击重新扫描，搜索草稿名称，然后按页面提示分析、提取或上传。

正常情况下不需要单独操作采集工具窗口，所有操作都在工作台网页完成。

## 使用其他工作台

如果任务要交给另一台电脑处理：

1. 在本机工作台点击“连接其他工作台”。
2. 粘贴负责人发来的工作台地址，或者直接双击负责人发来的 `打开公用工作台.url`。
3. 保持本机草稿采集工具开启。
4. 在打开的工作台网页中扫描并上传草稿。

地址只需设置一次，之后会自动记住。程序不再固定连接某一台电脑。

## 页面显示“本机草稿工具未启动”

1. 确认 `JianyingDraftCollector.exe` 正在运行。
2. 关闭后重新双击启动。
3. 刷新工作台网页。
4. 仍然无法连接时，查看日志：

`%LOCALAPPDATA%\JianyingDraftCollector\collector.log`

## 找不到草稿

1. 先在剪映里确认草稿名称和保存位置。
2. 回到工作台点击“重新扫描”。
3. 如果剪映草稿放在自定义目录，在页面的草稿目录设置中重新选择一次。

## 高版本草稿

高版本剪映草稿可能经过加密。采集工具会自动寻找本机剪映并尝试解密，不需要手工运行其他程序。解密只针对上传副本，不会修改原草稿。

## 关闭工具

完成草稿扫描和上传后可以关闭采集工具。正在分析或上传时不要关闭。

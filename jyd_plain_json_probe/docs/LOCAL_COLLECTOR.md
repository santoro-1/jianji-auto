# 剪映草稿采集工具使用说明

这个工具负责读取当前电脑上的剪映草稿，并把选中的草稿或素材送到“剪映批量剪辑工作台”。它不会自动导出视频。

本机完整工作台已经内置该功能，不需要另外启动本工具。只有当前电脑不运行完整工作台、而是通过浏览器访问其他公用工作台时，才需要单独使用这个采集工具。

程序已经包含运行环境，不需要安装 Python、Anaconda，也不需要输入命令。

## 使用前准备

1. 当前电脑已经安装剪映专业版。
2. 要采集的草稿能够在剪映中正常打开。
3. 把整个 ZIP 解压后使用，不要直接在压缩包里运行，也不要只复制 EXE。

## 每次怎么用

1. 双击 `JianyingDraftCollector.exe`。
2. 工具启动后会在后台运行，不会自动打开网页；保持它开启。
3. 再打开“剪映批量剪辑工作台”。
4. 在工作台选择“上传草稿”或“个人素材”。
5. 点击重新扫描，搜索草稿名称，然后按页面提示分析、提取或上传。

正常情况下不需要单独操作采集工具窗口，所有操作都在工作台网页完成。

## 使用其他工作台

如果任务要交给另一台电脑处理：

1. 在本机工作台点击“连接其他工作台”。
2. 粘贴负责人发来的工作台地址，或者直接双击负责人发来的 `打开公用工作台.url`。
3. 保持本机草稿采集工具开启。
4. 在打开的工作台网页中扫描并上传草稿。

地址只需设置一次，之后会自动记住。程序不再固定连接某一台电脑。

## 页面显示“本机草稿工具未启动”

1. 确认 `JianyingDraftCollector.exe` 正在运行。
2. 关闭后重新双击启动。
3. 刷新工作台网页。
4. 仍然无法连接时，查看日志：

`%LOCALAPPDATA%\JianyingDraftCollector\collector.log`

## 找不到草稿

1. 先在剪映里确认草稿名称和保存位置。
2. 回到工作台点击“重新扫描”。
3. 如果剪映草稿放在自定义目录，在页面的草稿目录设置中重新选择一次。

## 高版本草稿

高版本剪映草稿可能经过加密。采集工具会自动寻找本机剪映并尝试解密，不需要手工运行其他程序。解密只针对上传副本，不会修改原草稿。

## 保存到账号模板中心

1. 保持 `JianyingDraftCollector.exe` 开启。
2. 使用自己的数字人账号登录工作台，进入“剪映模板中心”。
3. 点击“从本机剪映导入”，选择草稿并填写模板名称。
4. 页面会依次分析、收集资源、打包，并保存到当前账号。

模板中心模式只保留主视频的占位结构，不上传旧主视频、旧语音和 BGM；花字、贴纸、字体、图片、
叠加视频和特效等视觉资源会随模板保存。上传使用十分钟内有效、仅能使用一次的账号凭证，采集器不会
接触账号密码或登录 Cookie。

模板导入时可以设置开头封面帧数（默认 3 帧，最多 30 帧）。系统会把从第 0 帧开始、持续时间很短、
且只被一个普通视频轨片段引用的照片识别为“封面人物图槽”。该人物照片副本在模板落地后会被删除，
不会成为账号模板的固定人物素材；同一时间段内的花字、贴纸、Logo、边框、装饰图片、遮罩和特效仍按
原草稿保存。使用模板生成成片时，人物图槽会换成当前项目生成基础视频时绑定的上传图片，并保留原槽位
的位置、缩放、裁剪和其他剪映片段属性。没有识别到短人物图槽的旧模板保持原行为。

通过浏览器访问其他电脑的工作台时，草稿仍由当前电脑上的采集器解密和打包，然后再通过局域网上传。
采集器的临时数据默认位于 `%LOCALAPPDATA%\JianyingDraftCollector`。上传结束后，迁移 ZIP 会立即
删除；上传成功后，对应的解密草稿副本也会删除，原始剪映草稿不会被修改或清理。上传失败时会暂时
保留解密副本以便重试，但不会保留 ZIP；超过 24 小时的临时包和解密副本会在采集器下次启动时清理。
可以通过 `JYD_COLLECTOR_TEMP_RETENTION_HOURS` 调整该保留时间。

采集器会把剪映 `##_draftpath_placeholder_*_##` 形式的草稿内路径解析到当前草稿目录，并按字体
资源 ID 合并同一字体在不同 Windows 用户目录下留下的新旧路径。只要草稿目录或当前剪映缓存中仍有
一份真实资源，模板导入就会上传该文件并统一重写全部旧路径；不会因为迁移电脑后残留的失效别名重复
报缺失。真正没有任何本地副本的叠加视频、抠像结果或特效资源仍会阻止上传，避免静默丢失模板效果。

如果页面提示“采集器版本过旧”，需要用新版采集器文件覆盖旧版本并重新启动。浏览器直接选择草稿目录
的方式仅作为备用方案，它不能自动读取草稿引用的本机缓存资源。

## 关闭工具

完成草稿扫描和上传后可以关闭采集工具。正在分析或上传时不要关闭。

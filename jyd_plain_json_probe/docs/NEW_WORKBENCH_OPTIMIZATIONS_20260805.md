# 新版工作台后续功能与质量优化（2026-08-05）

本文记录模块 0～8 原定范围完成后新增的需求。它们是后续功能和质量优化，不改变既有模块的
完成结论，也不得重写旧网页算法。正式实现前应为新增数据契约、素材目录和本地剪映处理分别
补充测试。

## 当前完成边界

- 模块 0～7 已完成。
- 模块 8 自动化闭环、旧任务隔离和完整回归已完成。
- 真实 MiniMax/RunningHub 付费联调、剪映桌面完整验收、服务器备份更新和正式本地软件打包
  尚未执行；这些工作需要用户明确授权及无人占用时段。
- 本文以下内容均为新增范围，不是模块 0～8 的遗留实现项。

## 1. 智能音乐匹配

### 音乐侧

每首音乐以稳定 `identity` 保存结构化画像，字段至少包括：

- 适用场景和情绪；
- 能量等级、节奏/BPM 和音乐密度；
- 纯音乐、轻人声或强人声；
- 开场方式、循环适配度和禁用场景；
- 标签来源、人工复核状态和 `taxonomy_version`。

可使用能够理解音频的模型批量生成建议标签，但不能只根据歌名推断。Excel/CSV 适合作为首批
标注、人工复核和批量导入导出工具，运行时权威数据应保存在音乐目录的结构化清单中。

### 脚本侧与选曲侧

云端文本模型只把脚本解析成固定 JSON `music_intent`，不直接挑选本地文件。本地工作台根据
音乐画像执行硬条件过滤、标签评分、最近使用降权和同批次去重，得到最终 `bgm_identity`。
选择结果应保存匹配理由、模型版本、提示词版本和标签版本，低置信度时回退到项目默认音乐或
人工选择。模块 6 继续冻结已选 BGM，背景音乐不参与变体变化。

## 2. 关键词语义局部前景素材

云端内容分析可与音乐意图共用一次请求，返回不含本地路径的语义锚点：

```json
{
  "visual_cues": [
    {
      "text": "鸡蛋",
      "char_start": 18,
      "char_end": 20,
      "concept_id": "food.egg",
      "asset_tags": ["鸡蛋", "早餐", "营养"],
      "importance": 0.85,
      "suggested_duration_ms": 1200
    }
  ]
}
```

MiniMax 返回字词时间戳后，服务端把字符位置映射为准确的 `start_us` 和 `duration_us`，并把
结果绑定脚本与音频版本。脚本或音频变化时旧 cue 必须失效。

模块 6 本地消费 cue，从本地图片库选择具体素材并放到数字人视频上层轨道。它是局部前景、
侧边卡片或透明素材，不是全屏插片，不切开或移动主视频轨道，也不改变语音和字幕时间轴。
所有 cue 必须在封面结束后才可出现，并避开人物脸部、主体和底部字幕安全区。

不同变体可改变具体素材、位置、尺寸、持续时间以及进入/退出动画；候选召回优先使用本地
词典，云端模型负责语境消歧、概念归一化和重要度判断。云端不可用时允许退化为纯词典模式。

## 3. 多段数字人人物跳变优化

当前正确流程保持不变：

```text
音频切分
  -> 多段音频并行提交 RunningHub
  -> 返回多个独立数字人视频片段
  -> 本地按顺序拼接
```

禁止把上一段最后一帧作为下一段生成输入。该方案会把并行任务退化为串行，显著增加总耗时，
并且不属于当前产品流程。

人物姿态跳变应在本地拼接或模块 6 后处理解决。第一版采用视频侧短转场：

- 在相邻数字人片段接缝使用约 4～8 帧的柔和模糊、轻微推近或极短淡化；
- 禁止明显闪白，避免长淡化产生双脸重影；
- 只处理视频画面，不移动语音和字幕时间轴，也不改变封面插入规则；
- 接缝附近存在合适语义 cue 时，允许局部前景素材跨越接缝以转移注意力；没有合适 cue 时
  使用通用短转场，不能插入无关图片；
- 后续可在本地比较相邻边界若干帧的人脸位置、姿态和亮度，选择差异较小的切点，但不得重新
  调用 RunningHub。

## 4. 推荐实施顺序

1. 本地短转场和现有封面、字幕、BGM、总时长回归。
2. 音乐与图片受控标签体系及本地结构化目录。
3. 云端 `content_analysis` 契约，一次返回 `music_intent` 与 `visual_cues`。
4. 字符锚点到 MiniMax 时间戳的确定性映射、版本绑定和缓存失效。
5. 模块 6 局部前景素材、批次内差异、人物/字幕避让、接缝遮挡与离线降级。

服务器、生产账号数据库和正式安装包不因记录本文而发生变化。

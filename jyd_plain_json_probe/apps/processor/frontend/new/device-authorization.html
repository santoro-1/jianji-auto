需要软件保护兼容模式？

仅在管理员允许时使用，保护强度低于 TPM。不会因 TPM 故障自动切换；已有设备应先修复原密钥。初始化后仍需管理员批准设备。

修复原设备密钥的访问权限

仅为运行工作台的 Windows 用户补充原密钥使用权限，不创建或替换密钥，不批准网站设备授权。请在实际处理机上完成 Windows 管理员确认。

等待授权的本地任务

仅显示当前账号的任务。继续前会重新校验本机授权，保留原任务，不重新生成云端视频。

什么时候不需要重新申请？

覆盖更新程序、移动安装目录、重启电脑、清除浏览器缓存或重新登录，都应沿用原设备授权。

如果重装系统或更换硬件导致密钥丢失，请联系管理员办理恢复或换机。不要反复申请，也不要复制别人的授权文件。
